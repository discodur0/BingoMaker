Bingo Card Generator

Add your squares, pick how many cards you need, and send each person their own link.

Used by short links and as the folder name, like …/bingo/1. Use a different name for each game so old games keep working.

Random card link

Send this one to everyone. Each person who opens it gets their own randomly dealt card.

Fixed cards, one per link, if you want to hand out specific cards.

To make the short links work:

1. Download cards.json and put it in a new folder named in the root of your repo, so it ends up at .
2. Once ever, add a copy of index.html named 404.html (that’s what lets /name/1 and /name/play open on GitHub Pages).
3. Commit and wait a minute.

New games with a different link name are just another folder, so earlier games keep working.
